## 使用方式

- CSV 统一保存为 UTF-8 BOM、CRLF 换行。浏览器若显示文本，可下载 ZIP 或使用文件页的下载按钮，不要保存成 HTML 后改扩展名。
- Excel 保留源工作表名称、第一行列名和这 5 条记录的值；样例重新生成，不携带原文件的其余行、隐藏数据、完整缓存或外链。原表公式按保存的结果值展示，因此精简样例不是完整计算模型。
- 日期时间及数值已与原文件的相应单元格核对。较长的 URL、描述等内容完整保留，可在编辑栏查看。
- 前 5 条样例不保证包含完整的 SKU、渠道、仓库或活动价格集合。正式导入前应换成自己的完整数据，再按脚本原有预演、试跑或核对流程操作。
- 首页已关联 5 份当前共享脚本实际使用的参考表；其余 18 份也提供下载，但不因此增加或发布相应业务脚本。
