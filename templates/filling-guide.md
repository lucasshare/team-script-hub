# 参考表填写说明

23 份文件均按用户要求保留了现用表的前 5 条数据。填写时保留第 1 行表头，从第 2 行替换、补充自己的数据。文件原有 `_副本` 等名称继续保留，不擅自合并来源不同的文件。

## 当前共享脚本用到的五份表

### 1. 库存查询：美发加仓库挑选顺序.csv

适用版本：库存查询 1.1.0。导入到“仓库优先级 CSV”。

脚本只读取“名称”列，按行顺序作为仓库优先级；渠道、所属仓区、地址、添加时间等列不参与这个脚本的导入。请替换为 OMS 的完整真实仓库名称，一行一仓，避免重复。样例只有前 5 个仓库，需要完整规则时应补全，不能直接用这 5 条替代所有仓库。

生成的推荐仓库映射供同一浏览器配置中的订单采集器使用，采集器无需另做一份输入表。

### 2. 填仓：商品尺寸数据表.xlsx

适用版本：仓库自动填充 3.20。导入到“商品尺寸数据”。

| 字段 | 填写说明 |
| --- | --- |
| 主SKU | 保留源表结构；当前脚本不按这一列匹配 |
| SKU | 与 OMS 当前任务的产品 SKU 精确对应，按文本保存 |
| 毛重 | kg，填写大于 0 的数字，不附加单位文字 |
| 包装长 | cm，填写大于 0 的数字 |
| 包装宽 | cm，填写大于 0 的数字 |
| 包装高 | cm，填写大于 0 的数字 |

不要把单位加入列名。同一 SKU 如果出现不同尺寸会被标记为冲突；应先核对再使用。

### 3. 填仓：仓库对照表.csv

适用版本：仓库自动填充 3.20。导入到“仓库对照表”。此表按列位置读取，前四列的顺序不能交换。

| 列序 | 字段 | 填写说明 |
| --- | --- | --- |
| 1 | 渠道（店铺-站点） | 与当前任务相符的完整渠道名称 |
| 2 | ERP 仓库名 | OMS 中对应的仓库名称 |
| 3 | Temu 仓库名 | 平台可选仓库的完整名称 |
| 4 | 平台仓库id | 已知真实 ID 时按文本完整填写，不自行编造 |
| 5 | 备注 | 可选，不参与匹配 |

渠道、ERP 仓库和平台仓库名称是有效关系所需字段。有 ID 时按 ID 定位，没有 ID 时仍要求完整名称唯一匹配。它用于跨系统仓库对照，与库存查询的“仓库优先级”不同，不能互换。

### 4. 面单下载：skuid_sku货号映射.csv

适用版本：面单批量下载 1.5.6。导入到 SKU 映射入口。

保留“SKU ID”和“SKU货号”两列，一行一组对应关系。SKU ID 应为完整的 TEMU 平台数字 ID，货号按文本保存；长 ID 不要变成科学计数法或让 Excel 改写末尾数字。同一 ID 不要填写不同货号，当前脚本会以后读到的值覆盖前面的值。

此表用于面单文件命名，不代替采集器建立的本批订单任务。

### 5. 活动精确退出：批量退活动.csv

适用版本：活动采集与精确退出 0.1.23。上传到“活动精确退出”页签。

这是现用表的 12 列版本，脚本从中识别店铺、SPU ID、完整活动名称及活动申报价格；SKU、颜色、站点等附加列保留作参照。它与脚本内置的四列最小空白模板列数不同，但兼容当前读取规则。

店铺须为当前账号可识别的名称或 ID，SPU ID 按文本保留完整数字，活动名称使用采集结果中的完整名称。多 SKU 或多站点活动的价格集合必须完整，前 5 条样例可能不包含完整集合，不能直接作为正式退出清单。

先使用默认勾选的试跑核对结果；只有明确选择正式提交并点击对应按钮，才执行退出。若额外填写“报名ID”，也必须使用真实、核实过的报名记录 ID。

## 其他参考表

其他 18 份保留用户现用文件的表头和前 5 条记录，用于查看填法，不据文件名猜测或新增共享脚本。多工作表的 Excel 每张表分别保留 5 条，跨表关联可能因截取不完整而不能作为完整计算或导入结果使用。

所有样例已重新生成。原文件留在用户本地，未被覆盖或删除；公开样例不包含原表其余数据、原外链、隐藏的完整工作表或完整计算缓存。
