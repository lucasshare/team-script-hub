# 首版需求与验收

日期：2026-11-11。依据：用户引用的 ChatGPT 对话及当前搭建请求。

## 已确定的范围

产品名称为“团队共享脚本中心”，首页展示“团队共享”标识，英文目录/仓库为 `team-script-hub`，名称不带特定平台。面向同事共享各平台脚本及通用工具，不限于 TEMU；一个脚本可以归属多个平台，平台选项从实际已发布清单动态生成。

Lucas 是唯一发布管理员，同事拿到公网链接就能使用，不建设登录后台。源码由 GitHub 私有仓库管理，静态文件交给 Cloudflare Pages。网站提供平台筛选、用途分类、搜索、版本、适用页面、安装按钮、使用说明和发布记录。

首版包含安装验证示例，用于验证网页到油猴的安装入口。它只在 example.com 显示提示，不假设或实现 TEMU 的业务接口。

## 验收要求

1. 搜索、平台和用途分类组合生效；多平台脚本在任一所属平台下都能找到。无匹配时显示提示；清单加载失败时显示错误和重试入口。
2. 手机和桌面均可阅读、操作；键盘焦点可见，交互控件有名称。
3. 安装链接指向真实 `.user.js`，更新检查指向 `.meta.js`，版本及名称与清单一致。
4. 发布路径跨版本保持固定，生产构建缺失正式域名必须失败。
5. 公网目录只包含页面及选中的发布文件，不包含文档、历史脚本和内部业务数据。
6. GitHub 自动运行检查；Cloudflare 连仓后负责部署，不添加付费资源。
7. GitHub 建仓、推送和 Pages 公网部署分别记录实际结果，不能把本地完成称为已上线。

## 后续范围

业务脚本接入、运行授权、安装统计、服务端审计和团队账号均不在首版。若后续需要这些能力，应重新对齐需求，并记录变更。
