# 团队共享脚本库需求与验收

日期：2026-11-12。当前版本按用户在主对话及“查找团队访问链接”对话的最新决定执行。

## 当前范围

产品名为“团队共享脚本中心”，仓库名为 `team-script-hub`，主要给同事共享多平台油猴脚本，名称不限定 TEMU。Lucas 独自管理发布，同事无需登录 GitHub即可查看公开首页及安装文件。

用户明确要求将仓库改为公开，直接使用 README 首页表格列出平台、脚本名称、用途、使用注意、当前版本和安装链接，不再搭建独立网站。这个决定替代早期私有源码仓库 + Cloudflare Pages 的方案；原 `tampermonkey-scripts` 开发仓库保持原样。

## 已确认脚本

用户在候选表中将第 26、49、70、72 项标为共享，并通过截图补充库存查询、ERP 订单采集器的完整面单工作流及活动采集脚本。去重后为 10 个业务脚本，另保留一个安装验证示例，版本见 [共享清单](shared-scripts.md)。

面单工作流为库存、采集、填仓、下载、按需删除、上传六项，分别安装并在首页写清配套关系。源文件保留原字节，分发只配置更新头，不改名称、命名空间、权限或业务正文。

## 验收

1. 只包含已确认的 10 个业务脚本及示例，保留当前最高版本，不额外共享候选表其余项目。
2. 首页表格包含原六列及新增“配套模板”列、每项的固定安装链接，面单六项配套关系明确。
3. 安装与更新文件直接从公开 GitHub 固定地址读取，元信息、版本和清单一致，正文及身份保持原样。
4. 公开前核对已有历史及本次内容，不能发布凭据、运行存储或未授权资料。业务数据默认排除；只保留与已共享脚本对应的 5 份模板，各保留前 5 条记录。
5. GitHub 自动检查通过，远端提交回读一致，公开状态和全部安装/更新链接可匿名访问。
6. 共享仓库发布不等于每位同事的店铺、浏览器和 Windows 环境已经通过实际业务运行验收。

暂不建设团队账号、运行授权、安装统计、服务端审计或独立网站。

## 2026-11-12 参考表补充需求

用户要求从现用对照表目录选取配套模板，只留大约 5 行数据作参照。随后明确纠正：只放已上传脚本对应的模板，而且每份表要放在对应脚本下面，方便查找。最终保留 4 个 CSV、1 个 Excel，共 5 份，放入对应 `userscripts/<脚本ID>/templates/`，说明写在同一脚本目录的 README。保持原文件名、工作表名、第一行表头及前 5 条非空数据记录；原文件不修改。

提供按脚本分组的目录、逐文件下载及 ZIP 合集。5 份表分别对应库存查询（1 份）、填仓（2 份）、面单下载（1 份）、活动退出（1 份），首页直接链接各脚本目录和填写说明。未关联当前共享脚本的表格从当前发布目录和 ZIP 移除；构建应拦截再次收录。正式运行前需要用户填入自己的完整数据。

验收包括原样例逐格比较、每张表行数上限、首行冻结、文本 ID 保留、ZIP 与独立文件一致、实际脚本解析器的隔离读取检查、公开下载回读；不执行真实业务动作，也不以样例试读替代同事环境验收。

补充交互要求：用户从首页对应脚本行点击“下载：文件名”即可保存 CSV/XLSX，填写说明独立提供；不能要求进入目录、打开原始文本再手动另存。下载附件与脚本目录中的模板须逐字节一致。
