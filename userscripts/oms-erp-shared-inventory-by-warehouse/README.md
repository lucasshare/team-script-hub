# OMS ERP 共享库存按仓库明细查询

当前共享版本：v1.1.0。

按自定义 SKU 查询各仓库存，依据仓库优先级和库存阈值生成推荐仓库。

## 配套模板

每份模板保留第 1 行表头和前 5 条数据，供参照填法；正式使用前请替换、补全自己的业务数据。原始业务表保持不变。

## 填写说明

### 美发加仓库挑选顺序.csv

适用版本：库存查询 1.1.0。导入到“仓库优先级 CSV”。

脚本只读取“名称”列，按行顺序作为仓库优先级；渠道、所属仓区、地址、添加时间等列不参与这个脚本的导入。请替换为 OMS 的完整真实仓库名称，一行一仓，避免重复。样例只有前 5 个仓库，需要完整规则时应补全，不能直接用这 5 条替代所有仓库。

生成的推荐仓库映射供同一浏览器配置中的订单采集器使用，采集器无需另做一份输入表。
