# Temu 仓库自动填充

当前共享版本：v3.20。

接收 OMS 批次，查询对应订单，并在普通下单或补发货页面填写尺寸与仓库。

## 配套模板

每份模板保留第 1 行表头和前 5 条数据，供参照填法；正式使用前请替换、补全自己的业务数据。原始业务表保持不变。

- [仓库对照表.csv](https://github.com/lucasshare/team-script-hub/releases/download/template-samples/warehouse-mapping.csv)
- [商品尺寸数据表.xlsx](https://github.com/lucasshare/team-script-hub/releases/download/template-samples/product-dimensions.xlsx)

## 填写说明

### 仓库对照表.csv

适用版本：仓库自动填充 3.20。导入到“仓库对照表”。此表按列位置读取，前四列的顺序不能交换。

| 列序 | 字段 | 填写说明 |
| --- | --- | --- |
| 1 | 渠道（店铺-站点） | 与当前任务相符的完整渠道名称 |
| 2 | ERP 仓库名 | OMS 中对应的仓库名称 |
| 3 | Temu 仓库名 | 平台可选仓库的完整名称 |
| 4 | 平台仓库id | 已知真实 ID 时按文本完整填写，不自行编造 |
| 5 | 备注 | 可选，不参与匹配 |

渠道、ERP 仓库和平台仓库名称是有效关系所需字段。有 ID 时按 ID 定位，没有 ID 时仍要求完整名称唯一匹配。它用于跨系统仓库对照，与库存查询的“仓库优先级”不同，不能互换。

### 商品尺寸数据表.xlsx

适用版本：仓库自动填充 3.20。导入到“商品尺寸数据”。

| 字段 | 填写说明 |
| --- | --- |
| 主SKU | 保留源表结构；当前脚本不按这一列匹配 |
| SKU | 与 OMS 当前任务的产品 SKU 精确对应，按文本保存 |
| 毛重 | kg，填写大于 0 的数字，不附加单位文字 |
| 包装长 | cm，填写大于 0 的数字 |
| 包装宽 | cm，填写大于 0 的数字 |
| 包装高 | cm，填写大于 0 的数字 |

不要把单位加入列名。同一 SKU 如果出现不同尺寸会被标记为冲突；应先核对再使用。
