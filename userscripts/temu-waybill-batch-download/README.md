## 填写说明

### skuid_sku货号映射.csv

适用版本：面单批量下载 1.5.6。导入到 SKU 映射入口。

保留“SKU ID”和“SKU货号”两列，一行一组对应关系。SKU ID 应为完整的 TEMU 平台数字 ID，货号按文本保存；长 ID 不要变成科学计数法或让 Excel 改写末尾数字。同一 ID 不要填写不同货号，当前脚本会以后读到的值覆盖前面的值。

此表用于面单文件命名，不代替采集器建立的本批订单任务。
